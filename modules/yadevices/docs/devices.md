# Устройства и умения

## Список устройств

Таблица показывает:

- устройство и его IoT ID;
- тип;
- навык;
- комнату и дом;
- количество привязанных умений;
- состояние;
- дату обновления.

Поиск ищет по названию, типу, комнате, дому, навыку и IoT ID. Станции показываются отдельной меткой, для остальных устройств доступен переключатель `on_off`.

## Фильтр по навыкам

Раскройте **Фильтр по навыкам**, чтобы скрыть устройства ненужных интеграций. Настройка сохраняется в конфиге модуля. Кнопка **Показать все** включает все навыки.

## Карточка устройства

### Название

Локальная подпись в MajorDoMo. Оригинальное имя Яндекса показывается ниже и не меняется.

### Идентификаторы

ID, IoT ID, тип, навык, дом, комната и дата обновления. Для станции есть ссылка на её карточку.

### Умения и связи

Каждое умение — отдельная карточка:

- тип (`capability` или `property`);
- понятное название;
- технический ключ;
- последнее значение;
- статус «привязано»;
- доступные параметры и признак «только чтение».

Для связи используются три поля:

- **Объект** — например, `Kitchen`;
- **Свойство** — например, `Light`;
- **Метод** — необязательно, получает команду вместо записи в свойство.

Поля используют стандартный компонент `linkedobject`: можно вводить вручную или выбирать из списка. Компонент сам подгружает свойства и методы выбранного объекта.

### Как это работает

- при изменении свойства в MajorDoMo модуль отправляет команду в Яндекс;
- при изменении состояния в Яндексе модуль обновляет привязанное свойство;
- если указан метод, он вызывается с параметром `VALUE`;
- для датчиков свойство обычно только читается.

## Типы устройств

Поддерживаются устройства Яндекса: свет, розетки, выключатели, реле, датчики, термостаты, камеры, шторы, увлажнители, кухонная техника, телевизоры, хабы и другие. Название и иконка определяются по `DEVICE_TYPE`.

## Станции в списке

Станция — тоже устройство Яндекса. Её умения (`local.*`, `cloud.*`) появляются в отдельной карточке. Для станций переключатель питания не показывается.

## Удаление

Удаление устройства снимает связи со свойствами объектов и удаляет его умения. Станции удаляются из своей карточки.
