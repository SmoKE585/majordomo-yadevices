# Станции и локальный режим

## Список станций

На странице **Станции** показаны карточки колонок:

- онлайн-статус;
- платформа и Station ID;
- режим TTS;
- локальная готовность (IP + токен);
- громкость и текущий трек.

Поиск ищет по названию, платформе, Station ID, IP и треку. Фильтр ограничивает список платформой.

## Карточка станции

### Основное

- **Название в MajorDoMo** — локальная подпись, имя в Яндексе не меняется.
- **IP станции** — нужен для локального Glagol. Кнопка с волшебной палочкой пытается определить IP автоматически.
- **Озвучивание событий** — выключено, локально или облако.
- **Минимальный уровень важности** — свойство или `%ThisComputer.minMsgLevel%`.
- **Вопросы ASK** — разрешает станции отвечать на вопросы сценариев.

### Доступ и токен

- Station ID, IoT ID, платформа и MDM ID;
- device token для локального режима;
- кнопка **Сформировать токен**;
- встроенный плеер для сцены.

Device token запрашивается у Яндекса по OAuth-токену. Если токен не получен, локальный режим недоступен.

### Локально или облако

| Режим | Плюсы | Ограничения |
| --- | --- | --- |
| Локальный | Быстро, не зависит от облака, работает диалог | Нужны IP и токен, порт 1961 |
| Облачный | Работает без локальной сети | Нужна авторизация, текст до 100 символов |

Если локальная отправка не удалась, модуль может автоматически повторить команду через облако.

### Привязки

- **Будильник** — свойство с датой/временем. При изменении создаётся будильник, при очистке — удаляется.
- **Вопрос Алисе** — текст из свойства отправляется через локальный Glagol.
- **Ответ Алисы** — текст ответа записывается в свойство.

Для выбора используется стандартный компонент `linkedobject`: объект, свойство и метод.

### Настройки станции

Читаются из Яндекса: DND, beta-функции, язык, яркость LED и визуализация. Поддерживаются не всеми платформами.

### Будильники

Можно создать вручную (дата и время) или через привязанное свойство. Список показывает дату, время, повтор и состояние.

### Тестирование

- текст, команда или диалог;
- локально или через облако;
- пресеты «Тестовое сообщение», «громкость 6», «включи мою музыку»;
- вопрос Алисе с ответом.

### Плеер

Плеер доступен по адресу `/module/yadevices.html?station=ID`. Параметры:

- `station` — ID станции;
- `bgcolor` — RGB фона;
- `textcolor` — цвет текста;
- `zoom` — масштаб.

Плеер подписывается на WebSocket-события `YADEVICES_TRACKS_*`, `YADEVICES_STATE_*`, `YADEVICES_ONLINE_*`.

## API

```php
callAPI('/api/module/yadevices', 'GET', array(
    'station' => 3,
    'command' => 'text',
    'data' => 'Тестовое сообщение',
));
```
