# Авторизация Яндекса

Авторизация нужна для списка станций, облачного TTS, сценариев и будильников. Локальный режим использует отдельный device token, но первичная загрузка станций всё равно требует входа.

## Способы входа

### QR-код

1. Откройте **Авторизация → QR-код**.
2. Отсканируйте код в приложении Яндекс («Умная камера»).
3. Дождитесь статуса «Авторизация завершена».

### Ссылка на вход

1. Откройте **Авторизация → Ссылка на вход**.
2. Нажмите **Открыть вход в Яндекс**.
3. Подтвердите вход в браузере, где уже есть нужный аккаунт.
4. Вернитесь в админку — статус обновится автоматически.

### Cookie-файл

Поддерживаются:

- Netscape cookie (`cookies.txt`);
- JSON-экспорт из расширения браузера;
- строка `name=value; name2=value2`.

Модуль нормализует файл и проверяет его через API Яндекса.

### x-token

Подходит для переноса авторизации из Home Assistant. Нужен **account x-token**, а не device token станции и не OAuth-токен Яндекс.Музыки. Токен проверяется перед сохранением.

### Пароль Я.Ключа

Одноразовый пароль действует 30 секунд. Способ оставлен для совместимости; для новых установок используйте QR-код.

## Что хранится локально

- cookie-файл `cms/yadevices/cookie.txt`;
- резервная копия `cookie.txt_back`;
- временные файлы `_qr` и `_otp` на время входа;
- `X_TOKEN`, `OAUTH_TOKEN` и `AUTHORIZED` в настройках модуля.

Файлы cookie не попадают в репозиторий: каталог `cms/yadevices/` исключён через `.gitignore`.

## Проверка и выход

- **Проверить** — запрашивает список устройств и подтверждает авторизацию.
- **Выйти** — удаляет cookie, x-token и OAuth-токен. Станции и устройства остаются в базе.

## Ошибки

| Симптом | Что проверить |
| --- | --- |
| «Не удалось создать сессию» | Доступ к `passport.yandex.ru`, системное время, прокси. |
| QR не сканируется | Обновите страницу и получите новый код. |
| Cookie не принят | Файл должен быть свежим и содержать cookie домена `.yandex.ru`. |
| x-token не прошёл проверку | Это не device token и не токен Музыки. |
| После входа нет станций | Нажмите «Обновить» и проверьте журнал модуля. |

## Безопасность

- Не используйте пароль администратора MajorDoMo.
- Не публикуйте cookie и x-token.
- Доступ к админке должен закрывать reverse proxy.
- После смены пароля Яндекса авторизацию нужно пройти заново.
