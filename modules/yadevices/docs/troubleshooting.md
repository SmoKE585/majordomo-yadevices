# Диагностика и частые ошибки

## Станции не загружаются

1. Проверьте **Авторизацию**: статус должен быть «авторизован».
2. Нажмите **Проверить** на странице авторизации.
3. Нажмите **Обновить**.
4. Посмотрите журнал модуля (`DebMes`, категория `yadevices`).

## Локальный режим не работает

- IP указан и доступен из сети MajorDoMo;
- порт 1961 открыт;
- device token сформирован;
- платформа поддерживает локальный Glagol;
- цикл `yadevices` запущен;
- кнопка **Проверить** рядом с IP показывает доступность.

Если локальная отправка не удалась, модуль попробует облако (если оно настроено).

## Облако не работает

- пользователь авторизован;
- станция поддерживает Cloud TTS;
- системный сценарий существует и активен;
- текст не длиннее 100 символов;
- на странице «Сценарии» нет ошибок.

## Команды не доходят

- станция онлайн;
- выбран правильный режим (локально/облако);
- для локального режима цикл запущен;
- очередь команд не переполнена;
- в журнале нет ошибок токена.

## Привязки не обновляются

- объект и свойство существуют;
- свойство не только для чтения;
- связь сохранена в карточке устройства;
- модуль подписан на событие `PropertySetHandle`;
- для методов проверьте имя метода и параметр `VALUE`.

## Ошибки авторизации

- cookie свежий;
- системное время верное;
- нет блокировки `passport.yandex.ru`;
- x-token — account token, не device token;
- после смены пароля войдите заново.

## Цикл не запускается

- проверьте состояние в X-Ray;
- нажмите кнопку запуска в карточке цикла;
- проверьте `cycle_yadevicesRun` в глобалах;
- посмотрите лог цикла.

## Журнал

Модуль пишет ошибки через `DebMes($message, 'yadevices')`. Включите **Мониторинг ошибок** в настройках, чтобы критические ошибки попадали в «Ошибки системы».

## Что приложить к обращению

- версию MajorDoMo и PHP;
- платформу станции;
- режим (локально/облако);
- текст ошибки из журнала;
- шаги, после которых ошибка появилась.
