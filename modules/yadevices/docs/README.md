# Я.Устройства — обзор

Модуль связывает **Яндекс Станции** и устройства умного дома с MajorDoMo. Внутреннее имя пакета — `yadevices`; в админке модуль называется **Я.Устройства**.

## Возможности

- **Станции.** Список колонок, онлайн-статус, громкость, текущий трек и плеер.
- **Локальное управление.** Команды через Glagol WebSocket на порт 1961.
- **Облачное управление.** Cloud TTS и облачные команды через сценарии Яндекса.
- **Умения устройств.** Capabilities и properties Яндекса связываются с объектами, свойствами и методами MajorDoMo.
- **Будильники.** Создание вручную и через свойство с датой/временем.
- **Вопросы Алисе.** Локальный диалог и запись ответа в свойство.
- **API.** Текст, команды, громкость и notify-группы через `callAPI()`.

## Быстрый старт

1. Установите модуль и откройте **Устройства → Я.Устройства**.
2. Пройдите **Авторизацию** в Яндексе (QR-код или ссылка на вход).
3. Нажмите **Обновить**.
4. Откройте карточку станции: укажите IP и сформируйте токен для локального режима.
5. Откройте карточку устройства и привяжите умения к свойствам объектов.

## Требования

- PHP 8.1+ и расширения `curl`, `mysqli`;
- доступ к Яндексу по HTTPS;
- для локального режима — IP колонки в локальной сети и открытый порт 1961.

## Совместимость

Сохраняются старые таблицы, API `/api/module/yadevices`, плеер `/module/yadevices.html?station=ID` и параметры вызова. Визуальная подпись изменена на **Я.Устройства**, но код пакета остался `yadevices`.
