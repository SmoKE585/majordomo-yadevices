# Сценарии и Cloud TTS

## Зачем нужны сценарии

Облачное озвучивание в Яндексе работает через сценарий: модуль обновляет текст шага и запускает сценарий. Для каждой станции создаётся отдельный системный сценарий с префиксом `мжд `.

## Страница сценариев

Показывает:

- название;
- статус (активен/отключён);
- список устройств;
- ID сценария;
- действия «Запустить» и «Удалить».

Системные сценарии Cloud TTS помечены отдельной строкой. **Не удаляйте их**, пока используете облачное озвучивание.

## Одноразовые сценарии

Таймеры и отложенные запуски показываются отдельными карточками с временем запуска.

## Создание Cloud TTS

1. Авторизуйтесь в Яндексе.
2. В карточке станции выберите режим **Облако Яндекса**.
3. Отправьте тестовую команду. Если сценария нет, модуль создаст его автоматически.
4. Если сценарий не обновился, удалите старый на странице «Сценарии» и отправьте команду снова.

Ограничения:

- текст до 100 символов;
- нужна авторизация;
- сценарий должен быть активен;
- для команд используется `text_action`, для озвучивания — `phrase_action`.

## Запуск из API

```php
callAPI('/api/module/yadevices', 'GET', array(
    'station' => 3,
    'command' => 'text',
    'data' => 'Сообщение через облако',
));
```

## Ошибки

| Симптом | Причина |
| --- | --- |
| Станция молчит | Сценарий удалён, отключён или не обновился. |
| Текст обрезан | Ограничение облака — 100 символов. |
| Сценарий не создаётся | Нет авторизации или станция не поддерживает Cloud TTS. |
| Сценарий не запускается | Проверьте статус на странице «Сценарии» и журнал модуля. |
