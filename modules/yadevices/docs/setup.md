# Установка и первичная настройка

## 1. Файлы

Скопируйте репозиторий в корень MajorDoMo так, чтобы сохранилась структура:

```text
modules/yadevices/
templates/yadevices/
public/assets/modules/yadevices/
scripts/cycle_yadevices.php
```

Модуль не требует Composer: все зависимости лежат рядом с кодом.

## 2. Установка

Откройте **Устройства → Я.Устройства**. При первом открытии модуль:

- создаёт таблицы `yastations`, `yadevices`, `yadevices_capabilities`;
- добавляет запись в `project_modules`;
- создаёт маркер `cms/modules_installed/yadevices.installed`;
- подписывается на события `SAY`, `SAYTO`, `ASK`.

## 3. Авторизация

Откройте **Авторизация** и выберите способ:

- **QR-код** — рекомендуемый;
- **Ссылка на вход** — если Яндекс уже открыт в браузере;
- **Cookie-файл** — перенос из браузера;
- **x-token** — перенос из Home Assistant;
- **Пароль Я.Ключа** — для совместимости.

После успешного входа модуль сохранит cookie и загрузит станции. Подробнее — [авторизация](auth.md).

## 4. Настройки модуля

| Поле | Назначение |
| --- | --- |
| Интервал опроса | Как часто обновлять онлайн-статус и громкость. 10–30 секунд для отладки, 1–5 минут для работы. |
| Мониторинг ошибок | Куда отправлять технические ошибки: «Ошибки системы» или DebMes. |
| Notify-группы | Наборы станций для отправки текста через API. |

Сохранение настроек перезапускает цикл `yadevices`.

## 5. Первая станция

1. Откройте карточку станции.
2. Проверьте название.
3. Для локального режима укажите IP и нажмите **Сформировать токен**.
4. Нажмите **Проверить** рядом с IP — порт 1961 должен быть доступен.
5. Выберите режим озвучивания: выключено, локально или облако.
6. При необходимости привяжите будильник, вопрос и ответ Алисы к свойствам объектов.

## 6. Цикл

Фоновый цикл `cycle_yadevices` обслуживает локальные WebSocket-соединения и очередь команд. Его состоянием можно управлять в карточке **Фоновый цикл модуля** на странице настроек или в X-Ray.

## Проверка

- список станций открывается без ошибок;
- после «Обновить» появились устройства;
- в карточке станции виден онлайн-статус;
- локальный порт 1961 доступен;
- тестовая команда «Тестовое сообщение» доходит до колонки.

Если что-то не работает — [диагностика](troubleshooting.md).
