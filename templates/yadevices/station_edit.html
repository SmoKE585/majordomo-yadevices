API

Примеры команд

Вызовы из сценариев MajorDoMo.

Простое сообщение
callAPI('/api/module/yadevices', 'GET', array('station' => [#ID#], 'command' => 'text', 'data' => 'раз-два-три'));
Notify-группа
callAPI('/api/module/yadevices', 'GET', array('group' => 'all', 'command' => 'text', 'data' => 'Текст'));
Громкость
callAPI('/api/module/yadevices', 'GET', array('station' => [#ID#], 'command' => 'setVolume', 'data' => 6));
Эффект речи
callAPI('/api/module/yadevices', 'GET', array('station' => [#ID#], 'command' => 'text', 'data' => '<speaker effect="megaphone">Ехал Грека через реку'));
